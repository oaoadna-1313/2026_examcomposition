## 💡 系統四大教學板塊特色

1. **板塊一：立意取材與審題心智圖**
   - 文眼聚焦、立意層次（寫實 ➔ 經驗 ➔ 哲理）、素材聯想與啟發式提問。
2. **板塊二：段落結構與 Chart.js 配速**
   - 【問津趕行程】五段標準架構（起承轉合），搭配視覺化甜甜圈圓餅圖連動。
3. **板塊三：AI 智慧教練與純淨累積區**
   - 靈感骰子、快捷提示詞注入、即時打字機串流、純淨 6 級分潤飾一鍵採納。
4. **板塊四：教師巡桌專區與 6 級分範文賞析**
   - 分層檢核指標（基礎/進階/挑戰），附完整 700~900 字滿級分範文解剖。
